repo run api

Why it exists

Labs, vitals, habits, income — one row per patient. Target is high vs low attack risk. About a third of the train set is the high class. Nine lifestyle fields are empty on the same 243 people. A majority classifier looks accurate and is useless for screening. I trained for F1-macro and put the model behind FastAPI so a batch job can hit it without opening a notebook.

Numbers I will defend

8 685train rows
966test rows
35%high-risk in train
0.54CV F1-macro ± 0.008

Train-set report sits near 0.90. That’s memorization. CV is the number. Test labels aren’t in this repo; the scored file flags 380 / 966 as high (~39%), so the threshold isn’t glued to the majority class.

Stack on the wire

Preprocessor (medians + category maps, frozen column order) → CatBoost (depth=6, 500 iterations, balanced class weights) → id, prediction.
